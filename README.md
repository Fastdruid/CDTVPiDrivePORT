# Amiga CDTV PiDrivePORT Driver for CDTV PiDrive and PicoDrive

This is an implementation of a SANA-II driver for the Amiga, which allows you to use either a PicoW based CDTV PicoDrive, or Zero 2W based CDTV PiDrive to give internet access to the machine!

This code was originally based on the [DaynaPORT](https://github.com/RobSmithDev/daynaport-amiga) by RobSmithDev which in turn was originally based on the MNT ZZ9000Net driver by Lukas F. Hartmann (which is based on work by Henryk Richter) and also borrows a little from the PlipBox device driver, which has several contributors.
